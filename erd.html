Oracle 9i ERD 가져오기 (SQL 생성 & Orange 결과 붙여넣기)

1단계. 테이블명 입력 → Oracle 9i 쿼리 복사

테이블명을 쉼표(,), 공백 또는 줄바꿈으로 구분해 입력하면 Oracle 9i 호환 쿼리가 자동 생성됩니다. (Owner 미입력 시 현재 접속 계정의 USER_* 뷰 조회)

2단계. Orange 조회 결과 붙여넣기 (TSV / CSV)

Orange에서 위 SQL 실행 후 결과 그리드에서 전체 선택(Ctrl+A) → 복사(Ctrl+C)한 텍스트를 그대로 붙여넣으세요. 헤더 행 및 맨 앞 행 번호 컬럼은 자동으로 처리됩니다.
